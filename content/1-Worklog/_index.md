## Internship Worklog Overview

This worklog records my learning and practical work in the **First Cloud AI Journey** program, progressing from AWS fundamentals to the ideation, design, and implementation of CampusMeet. It currently covers nine weeks from **8 June 2026 to 8 August 2026**.

### Weeks 1–3: Onboarding and AWS Foundations

- **[Week 1 (8–13 June)](1.1-week1/):** Internship admission, program and company onboarding, team formation, AWS Budgets, and IAM.
- **[Week 2 (15–20 June)](1.2-week2/):** VPC, subnets, Internet Gateway, route tables, EC2, Security Groups, and a test application deployment.
- **[Week 3 (22–27 June)](1.3-week3/):** IAM Roles for EC2, AWS CloudShell, Amazon S3, and static website hosting.

### Weeks 4–6: Advanced AWS Services and Project Ideation

- **[Week 4 (29 June–4 July)](1.4-week4/):** Amazon RDS, Lightsail, Launch Templates, and EC2 Auto Scaling.
- **[Week 5 (6–11 July)](1.5-week5/):** CloudWatch, SNS alarms, Route 53, Hybrid DNS, AWS CLI, and scripting.
- **[Week 6 (13–18 July)](1.6-week6/):** Knowledge review, problem discovery, and project idea evaluation.

### Weeks 7–9: CampusMeet Design and Development

- **[Week 7 (20–25 July)](1.7-week7/):** User research, CampusMeet proposal, scope agreement, and initial team assignments.
- **[Week 8 (27 July–1 August)](1.8-week8/):** Requirements, UI flows, architecture, data model, and API contracts.
- **[Week 9 (3–8 August)](1.9-week9/):** Monorepo standardization, module implementation, Google integration, orchestration, reviews, and testing.

Each weekly page records activities from Monday through Saturday, references, outcomes, difficulties, and resolutions.
